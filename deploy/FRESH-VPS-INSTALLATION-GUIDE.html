2. Point the domain to the new VPS

In the DNS manager for marichomedia.com, create or update this A record:

Type:   A
Name:   mshauri
Value:  64.247.178.45
TTL:    300 (or Auto)

Wait for DNS to update, then check it from the VPS:

nslookup mshauri.marichomedia.com
# Expected IP: 64.247.178.45
Do not request HTTPS yet. The DNS check above must return the new IP first, otherwise the SSL certificate request will fail.

3. Log in and download the code

1

Connect to the server

ssh root@64.247.178.45
2

Clone the GitHub repository

cd /var/www
git clone https://github.com/seanndlovu/Mshauri-AI-Advisor.git mshauri
cd /var/www/mshauri

If the folder already exists because a previous setup attempt was made, use this instead:

cd /var/www/mshauri
git pull origin main

4. Install server software

3

Run the installer once

cd /var/www/mshauri
sudo bash deploy/1-install-vps.sh

This installs Node.js 24, pnpm, PM2, PostgreSQL, Nginx and Certbot. It may take several minutes.

4

Check for another web server on port 80

sudo lsof -i :80

If the output shows apache2, stop it before the next step:

sudo systemctl stop apache2
sudo systemctl disable apache2

5. Create the production settings file

5

Generate secure local secrets

# Copy each output somewhere safe until the next step.
openssl rand -hex 24   # DB_PASS
openssl rand -hex 32   # SESSION_SECRET
6

Create and edit the environment file

cd /var/www/mshauri
cp deploy/.env.example deploy/.env.production
nano deploy/.env.production

Replace the placeholder values only. Do not add DATABASE_URL; the deployment scripts generate it safely from your database password.

PORT=8080
NODE_ENV=production
DOMAIN=mshauri.marichomedia.com

DB_NAME=mshauri
DB_USER=mshauri
DB_PASS=PASTE_THE_FIRST_OPENSSL_VALUE_HERE

SESSION_SECRET=PASTE_THE_SECOND_OPENSSL_VALUE_HERE

# Leave as sk-... only if AI chat is not ready yet.
OPENAI_API_KEY=sk-PASTE_YOUR_OPENAI_KEY_HERE

# Leave placeholders only if WhatsApp is not ready yet.
WHATSAPP_ACCESS_TOKEN=PASTE_META_ACCESS_TOKEN_HERE
WHATSAPP_PHONE_NUMBER_ID=PASTE_META_PHONE_NUMBER_ID_HERE
WHATSAPP_VERIFY_TOKEN=YOUR_PRIVATE_VERIFY_TOKEN

Save in Nano with Ctrl+X, then Y, then Enter.

6. Build and start Mshauri

7

Run the full deployment

cd /var/www/mshauri
bash deploy/2-setup-app.sh

This creates the PostgreSQL user and database, installs packages, builds the API and frontend, applies the database schema, creates the Nginx site, and starts the API with PM2.

Expected finish: the script prints Mshauri is running!. If it stops with an error, copy the complete last 20 lines of the terminal before continuing.

7. Add HTTPS (SSL)

8

Create the certificate after DNS is correct

sudo certbot --nginx -d mshauri.marichomedia.com

When asked whether to redirect HTTP to HTTPS, choose 2 — Redirect.

sudo certbot renew --dry-run

8. Add starter communities and posts

9

Seed the empty production database once

cd /var/www/mshauri
pnpm --filter @workspace/scripts run seed:community

This adds the starter farming communities and example discussions. It is safe to skip if you prefer the site to begin empty.

9. Required final verification

10

Run all four checks

# API is running
pm2 status

# API responds locally
curl http://localhost/api/healthz

# Nginx configuration is valid
sudo nginx -t

# Public HTTPS site responds
curl -I https://mshauri.marichomedia.com

Then visit https://mshauri.marichomedia.com in a browser and test:

  • Home page loads without a 502 or 404 error.
  • A user can register and sign in.
  • Community pages load.
  • Ask Mshauri AI works, if an OpenAI key was added.

10. Future updates

After new code has been pushed to GitHub, update the live site with:

cd /var/www/mshauri
bash deploy/3-update.sh

The update script pulls new code, rebuilds both applications, applies any database schema changes, and restarts the API.

Troubleshooting

ProblemCommand to investigate or fix
API is not running / browser shows 502pm2 logs mshauri-api --lines 100
pm2 restart mshauri-api --update-env
Domain does not opennslookup mshauri.marichomedia.com — must show 64.247.178.45
HTTPS certificate failsFix the DNS record first, wait for propagation, then rerun the Certbot command.
Nginx errorssudo nginx -t
sudo systemctl reload nginx
Need to inspect app errorspm2 logs mshauri-api --lines 100
Build runs out of memorysudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile, then rerun Step 7.

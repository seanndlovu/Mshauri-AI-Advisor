Deployment Steps

0
DNS — Point the domain at the server
Do this FIRST — wait 15 min before Step 7

In Maricho Media's DNS manager, add an A record:

# DNS A Record settings
Type :  A
Name :  mshauri
Value:  50.6.195.160
TTL  :  300 (or Auto)

Verify propagation before continuing:

nslookup mshauri.marichomedia.com
# Must return: 50.6.195.160
1
SSH into the server
ssh root@50.6.195.160
2
Stop Apache (Virtualmin conflict)
⚠️
Virtualmin installs Apache on port 80. This app uses Nginx — both cannot run on port 80 at the same time. If other websites on this server use Apache, discuss with the client before proceeding.
# Check what is on port 80
sudo lsof -i :80

# Stop Apache and prevent it from restarting on reboot
sudo systemctl stop apache2
sudo systemctl disable apache2

# Confirm it is stopped (should say: inactive)
sudo systemctl status apache2
3
Clone the repository
cd /var/www
git clone https://github.com/seanndlovu/Mshauri-AI-Advisor.git mshauri
cd mshauri
4
Install all server software
Run once — takes 3–5 minutes 
sudo bash deploy/1-install-vps.sh

This installs: Node.js 24, pnpm, PM2, PostgreSQL 16, Nginx, Certbot

✅
Script ends with: All dependencies installed. — if it fails partway, it is safe to run again.
5
Generate your secrets
# Generate SESSION_SECRET (copy the output — you will need it below)
openssl rand -hex 32

Write down the output — paste it into the env file in the next step.

6
Configure environment variables
cp deploy/.env.example deploy/.env.production
nano deploy/.env.production

The file is pre-filled with the domain and port. Only update the values marked in red:

# Server
PORT=8080
NODE_ENV=production
DOMAIN=mshauri.marichomedia.com

# Database
DB_NAME=mshauri
DB_USER=mshauri
DB_PASS=your_strong_db_password
DATABASE_URL=postgresql://mshauri:your_strong_db_password@localhost:5432/mshauri

# Session (paste openssl output here)
SESSION_SECRET=paste_openssl_rand_hex_32_output_here

# OpenAI
OPENAI_API_KEY=sk-...

# WhatsApp
WHATSAPP_ACCESS_TOKEN=paste_from_meta_business_manager
WHATSAPP_PHONE_NUMBER_ID=paste_from_meta_business_manager
WHATSAPP_VERIFY_TOKEN=any_string_you_choose
⚠️
Important: DB_PASS must match exactly in both the DB_PASS= line and inside DATABASE_URL=. Copy carefully.

Save and exit nano: Ctrl+X → Y → Enter

7
Build and launch the app
Takes 2–4 minutes 
bash deploy/2-setup-app.sh

This script automatically:

  • Creates the PostgreSQL database and user
  • Installs all Node.js packages
  • Builds the API server and frontend
  • Creates all database tables
  • Writes and activates the Nginx config
  • Starts the API with PM2 (auto-restarts on crash or reboot)
✅
Expected final output:
Mshauri is running! → http://mshauri.marichomedia.com

Verify the API is responding:

curl http://localhost/api/healthz
# Expected response: {"status":"ok"}
8
Add HTTPS / SSL certificate
⚠️
HTTPS is required. User logins will not work without it. DNS from Step 0 must be pointing at the server before this step.
sudo certbot --nginx -d mshauri.marichomedia.com

When prompted:

  • Enter an email address for renewal notices
  • Agree to terms → type Y
  • Redirect HTTP → HTTPS → choose 2 (Redirect)

Test the auto-renewal works:

sudo certbot renew --dry-run
✅
Certificate auto-renews every 90 days — no manual action needed.
9
Final verification
# 1. Open in browser
https://mshauri.marichomedia.com

# 2. API health check
curl https://mshauri.marichomedia.com/api/healthz

# 3. PM2 process status
pm2 status

# 4. View live API logs
pm2 logs mshauri-api --lines 50

Deploying Future Updates

Whenever new code is pushed to GitHub, run this on the server:

cd /var/www/mshauri && bash deploy/3-update.sh

Pulls latest code, rebuilds everything, and restarts the API. Takes about 2 minutes.

Reference Commands

PM2 — API process manager

pm2 status             # is API running?
pm2 logs mshauri-api   # live logs
pm2 restart mshauri-api # restart
pm2 stop mshauri-api   # stop

Nginx — web server

sudo nginx -t           # test config
sudo systemctl reload nginx
sudo journalctl -u nginx -f

Troubleshooting

Problem Likely cause Fix
Port 80 already in use Apache still running sudo systemctl stop apache2 && sudo systemctl disable apache2
502 Bad Gateway in browser Node/PM2 process crashed pm2 restart mshauri-api && pm2 logs mshauri-api
Login doesn't work HTTPS not configured Run Step 8 (Certbot)
Certbot says "domain not found" DNS not propagated yet Wait 15 min, verify with nslookup mshauri.marichomedia.com
DATABASE_URL error on startup Password mismatch in .env Fix .env.production then re-run bash deploy/2-setup-app.sh
Build crashes / out of memory Not enough RAM during build sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile — then retry build

How It Works

Browser (HTTPS port 443)
    │
    ▼
Nginx (reverse proxy)
    ├── /api/*   →  Node.js API on port 8080 (managed by PM2)
    │                  └── connects to PostgreSQL on port 5432 (local only)
    └── /*     →  Static frontend files (artifacts/mhauri-ai/dist/)

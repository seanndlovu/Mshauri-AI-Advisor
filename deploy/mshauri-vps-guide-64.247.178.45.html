Step-by-Step Setup

0
DNS — Point your domain at the server
Do this first — DNS takes 5–15 min to propagate

In your DNS manager (wherever marichomedia.com is registered), add:

Type :  A
Name :  mshauri
Value:  64.247.178.45
TTL  :  300

Verify after 10–15 min (SSL won't work until this resolves):

nslookup mshauri.marichomedia.com
# Must show: 64.247.178.45
1
SSH into the server
ssh root@64.247.178.45
2
Clone the repository from GitHub
cd /var/www
git clone https://github.com/seanndlovu/Mshauri-AI-Advisor.git mshauri
cd mshauri
3
Install all server software
Runs once — takes 3–5 minutes
sudo bash deploy/1-install-vps.sh

Installs: Node.js 24 · pnpm · PM2 · PostgreSQL 16 · Nginx · Certbot

✅
Ends with: All dependencies installed. — safe to re-run if it fails partway.
4
Generate your SESSION_SECRET
# Run this and copy the output — paste it in Step 6
openssl rand -hex 32
5
Check if Apache is running on port 80
⚠️
Some Ubuntu installs have Apache active on port 80. This will conflict with Nginx. Check and disable it.
sudo lsof -i :80
# If you see apache2 in the output, run these:
sudo systemctl stop apache2
sudo systemctl disable apache2
6
Configure environment variables
cp deploy/.env.example deploy/.env.production
nano deploy/.env.production

Fill in the file exactly like this — replace the red values:

# ── Server ──────────────────────────────
PORT=8080
NODE_ENV=production
DOMAIN=mshauri.marichomedia.com

# ── Database ─────────────────────────────
DB_NAME=mshauri
DB_USER=mshauri
DB_PASS=your_strong_password_here
DATABASE_URL=postgresql://mshauri:your_strong_password_here@localhost:5432/mshauri

# ── Session ──────────────────────────────
SESSION_SECRET=paste_openssl_output_here

# ── OpenAI ───────────────────────────────
OPENAI_API_KEY=sk-...

# ── WhatsApp ─────────────────────────────
WHATSAPP_ACCESS_TOKEN=paste_from_meta_business
WHATSAPP_PHONE_NUMBER_ID=paste_from_meta_business
WHATSAPP_VERIFY_TOKEN=any_word_you_choose
⚠️
Important: DB_PASS must be identical in both the DB_PASS= line AND inside DATABASE_URL=. Copy carefully.

Save and exit: Ctrl + X → Y → Enter

7
Build and launch the app
Takes 2–4 minutes
bash deploy/2-setup-app.sh

Automatically: creates database · installs packages · builds app · configures Nginx · starts API with PM2

✅
Ends with: Mshauri is running! → http://mshauri.marichomedia.com

Verify the API is up:

curl http://localhost/api/healthz
# Expected: {"status":"ok"}
8
Add HTTPS / SSL certificate
⚠️
HTTPS is required — user logins will not work without it. DNS (Step 0) must be pointing at the server before this step works.
sudo certbot --nginx -d mshauri.marichomedia.com
# When prompted about redirect → choose 2 (Redirect HTTP to HTTPS)

Test that auto-renewal works:

sudo certbot renew --dry-run
✅
Certificate renews automatically every 90 days — no manual action needed.
9
Seed with starter content (communities & demo posts)
pnpm --filter @workspace/scripts run seed:community

Creates 10 farming communities, 3 demo user accounts, 32 posts, and 69 comments so the app is not empty on launch.

ℹ️
Demo accounts: tendai@demo.zw / chipo@demo.zw / farai@demo.zw — all use password demo1234
10
Final check — open in browser
# Visit in browser
https://mshauri.marichomedia.com

# API health check
curl https://mshauri.marichomedia.com/api/healthz

# PM2 status
pm2 status

# View live logs
pm2 logs mshauri-api --lines 50

Deploying Future Updates

After any new code is pushed to GitHub, run this on the server:

cd /var/www/mshauri && bash deploy/3-update.sh

Pulls latest code, rebuilds, restarts API. Takes ~2 minutes. No downtime for users during frontend rebuild.

Useful Commands

PM2 — API process manager

pm2 status              # running?
pm2 logs mshauri-api    # live logs
pm2 restart mshauri-api # restart
pm2 stop mshauri-api    # stop

Nginx — web server

sudo nginx -t            # test config
sudo systemctl reload nginx
sudo journalctl -u nginx -f

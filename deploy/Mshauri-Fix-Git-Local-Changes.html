Fixing the VPS Git Update Error

Safe instructions for the “local changes would be overwritten by merge” error

Repository folder/var/www/mshauri
Conflicting filepnpm-workspace.yaml
Error shown on the VPS: 
error: Your local changes to the following files would be overwritten by merge:
  pnpm-workspace.yaml
Please commit your changes or stash them before you merge.
Aborting

What this means

The VPS has a local edit to pnpm-workspace.yaml. GitHub also has a newer version of that file. Git stops the update instead of silently deleting the VPS edit.

This file is part of the application source code. VPS-only settings such as passwords, Clerk keys, session secrets and the Owner email belong in deploy/.env.production, not in pnpm-workspace.yaml.

Recommended safe fix

1

Enter the Mshauri folder

cd /var/www/mshauri
2

Back up the local change

This saves a copy outside the repository before restoring the GitHub version.

git diff -- pnpm-workspace.yaml > /root/pnpm-workspace-local-change.diff
ls -lh /root/pnpm-workspace-local-change.diff
3

Confirm the file is the only change

git status --short

You should see pnpm-workspace.yaml as the conflicting modified file.

4

Restore only the conflicting source file

git restore pnpm-workspace.yaml

This does not remove deploy/.env.production because that file is separate and should remain local to the VPS.

5

Run the normal update

bash deploy/3-update.sh

The script pulls the current code, installs packages, builds the application, applies database changes and restarts the API.

After the update

Check that the API restarted successfully:

pm2 status
pm2 logs mshauri-api --lines 50

Check the website:

curl -I https://mshauri.marichomedia.com

Then open the website in a browser and sign in.

If the error appears again

Run these commands and review all modified files:

cd /var/www/mshauri
git status --short
git diff --stat
Stop if files other than pnpm-workspace.yaml are modified. Do not restore or delete those files until their purpose is confirmed. In particular, do not delete deploy/.env.production or any advert upload directory.

Do not use this shortcut

git reset --hard

Do not use a hard reset as the first fix. It can delete local tracked changes and make recovery harder. The recommended procedure backs up and restores only the known conflicting file.

Optional: inspect the saved change

less /root/pnpm-workspace-local-change.diff

If the file contains a useful project change that should be kept, send the diff to the developer for review rather than editing it directly on the production VPS.

Quick version

cd /var/www/mshauri
git diff -- pnpm-workspace.yaml > /root/pnpm-workspace-local-change.diff
git restore pnpm-workspace.yaml
bash deploy/3-update.sh

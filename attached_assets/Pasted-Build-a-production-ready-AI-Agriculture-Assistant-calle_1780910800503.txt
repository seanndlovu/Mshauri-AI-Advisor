Build a production-ready AI Agriculture Assistant called "Mhauri AI" for Maricho Media.

IMPORTANT:

This is NOT a demo project.

This must be production-ready, secure, scalable, and deployable.

The goal of Phase 1 is to create a working WhatsApp agricultural assistant for Zimbabwean farmers.

Do NOT build unnecessary complexity.

Ignore the following for now:

* Qdrant
* Vector Databases
* RAG
* Farmer Profiles
* Subscription Billing
* Paynow
* Admin Dashboard
* Analytics
* Multi-tenancy

These will be added later.

MESSAGE FLOW

When a WhatsApp message arrives:

1. Extract sender number.
2. Extract text message.
3. Send text to GPT-5-mini.
4. Use agricultural system prompt.
5. Receive response.
6. Send response back to WhatsApp.

SYSTEM PROMPT

You are Mhauri AI.

You are an agricultural extension officer for Zimbabwe.

Provide practical, actionable farming advice.

Focus on:

* Crop production
* Livestock management
* Pest control
* Disease management
* Soil fertility
* Irrigation
* Climate-smart agriculture

Support:

* English
* Shona
* Ndebele

If uncertain:

Clearly state uncertainty.

Do not invent facts.
